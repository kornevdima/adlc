# cqrs-journey

Summary of Microsoft patterns & practices, *Exploring CQRS and Event Sourcing* (the CQRS Journey).

- CQRS and event sourcing are separate patterns; the guide uses them together in some bounded contexts and CQRS alone in others.
- Apply CQRS per bounded context, not system-wide.
