# Architecture Notes: LLM Wiki

A small knowledge base about distributed-systems patterns, kept by an agent with the adlc wiki skills.

- Hot cache: `wiki/hot.md` (read first). Index: `wiki/index.md`. Log: `wiki/log.md` (newest entry at the top).
- Sources in `.raw/` are immutable. Generated pages live in `wiki/`.
- Concept pages carry `complexity:` in frontmatter from now on.
