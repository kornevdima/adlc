# RACI and the responsibility assignment matrix

Built from search results only (no page fetch; the fetch budget was spent on the framework pages). The sources are Wikipedia's entry and a PMI community site. Confidence is medium. The PMBOK wording itself was not seen, so the PMBOK link is secondary.

## The four letters

- Responsible: does the work. There can be several.
- Accountable: signs off and answers for the result. Exactly one per task or deliverable.
- Consulted: gives input before the work is done.
- Informed: told after the decision.

## The one-A rule

Zero Accountable means nobody owns the task; two means decisions stall. Wikipedia hedges that this holds "according to some theories", while exam-prep sources state it flatly. One person may be both A and R on a small team; larger projects separate them.

## Scope

RACI is one form of responsibility assignment matrix. PMBOK lists such matrices as a tool but, per one source, does not prescribe RACI.
