# Obsidian Bases documentation

The official help page for Bases, an Obsidian core plugin. The old address (help.obsidian.md/bases) redirects to the URL above. The page carries no date.

## What it states

- A base is a database-like view of notes. You view, edit, sort and filter files and their properties. The data stays in the Markdown files and their properties; the base holds only the view definition, saved as a `.base` file or embedded in a code block.
- In a table view each row is a file and each column is a property. One base can hold several views.
- Formulas compute values from other properties. A separate Functions page lists what formulas and filters can use.
- The built-in view types are Table, List, Cards, Kanban and Map. Community plugins can add more.
- The Kanban view displays files as cards organized into columns based on a grouped property.

## What it does not state

The overview page names filtering, sorting and grouping but explains them on the Views page, which was not fetched.

## Relevance

A board whose columns come from a note's `status` property is a documented built-in, not a workaround. The board holds no state of its own (Source: [[obsidian-bases-help]]). Used in [[Knowledge Layer and Work Tracker Split]].
