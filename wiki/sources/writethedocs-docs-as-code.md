# Write the Docs: docs as code

A community guide from Write the Docs. The page shows no publication date; it lists talks from 2015 to 2022 and a 2026 conference, so it is maintained, not frozen. Confidence is medium because it is a community guide and states a practice, not a measured result.

## Claims

- Docs as code is a philosophy of writing documentation with the same tools as code, applying development workflows to docs.
- Tools named: issue trackers, version control with Git, plain-text markup (Markdown, reStructuredText, AsciiDoc), code review and automated tests. It also names docToolchain, an open-source toolchain for the approach.
- It builds a culture where writers and developers both own the docs. Developers often write a first draft, and writers integrate better with development teams.
- Teams can block a feature merge that lacks documentation, so features are documented while fresh.

## Relevance

Supports keeping the knowledge layer in the code repository with the same review and history as code (Source: [[writethedocs-docs-as-code]]). Used in [[Knowledge Layer and Work Tracker Split]].
